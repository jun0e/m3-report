Architecture

How tomorrow's report gets made.

Run node daily-report.js --date=YYYY-MM-DD. The orchestrator tries the new HTTP API (https://m3new-alpha-log.service.zingplay.com/download?date=…) first, falls back to a local zip if 404. It then runs three sub-scripts in sequence: pipeline.js (12-tab dashboard) · analyze-ab-cutscene.js (GrowthBook causal split) · analyze-cutscene-segments.js (engaged-vs-insta-skip within-arm segmentation). Outputs land in a per-date folder; gen-cutscene-report.js produces the standalone HTML cutscene report from the JSONs.
